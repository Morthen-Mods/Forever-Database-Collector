# Forever Database Collector

**Help build the Forever Database just by playing.**

Forever Database Collector quietly records quest, NPC, object, item and loot information while you play, and lets you export it with a few clicks. Paste the export into the Forever Database website and your observations help keep the database complete and accurate for everyone.

## Features

- **Runs in the background** – no setup needed, just install and play
- **Quests** – texts, objectives, rewards, quest givers and turn-ins, plus the race/class/faction requirements
- **NPCs & objects** – names, texts and spawn positions
- **Loot** – what drops from creatures and objects; every corpse you loot is recorded, and reopening the same corpse doesn't count twice
- **Vendors** – what NPCs sell
- **Items & zones** – basic item details and map information
- **Minimap button** – hover to see how much you've collected, click to export
- **English and German** clients supported

## How to contribute

1. Play as usual – the addon collects data automatically.
2. Type `/fdb export` or click the minimap button.
3. Copy the text with **Ctrl+C**.
4. Paste it on **<website-url>/import**.
5. Click **"Copied – clear data"** so your next export only contains new findings.

## Commands

| Command | Effect |
| --- | --- |
| `/fdb` | Show how much has been collected so far |
| `/fdb export` | Open the export dialog |
| `/fdb minimap` | Show or hide the minimap button |
| `/fdb debug` | Show collector errors in chat |

## Privacy

The addon does **not** send anything anywhere – WoW addons can't access the internet. Data only leaves your game when you copy the export and paste it on the website yourself.

The export contains your **realm and character name**, which the website uses to recognize trusted contributors. Everything else is game data.
